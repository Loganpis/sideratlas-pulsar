# Original gamma-ray comparison inputs

These are the original Fermi-LAT 3PC pulse and spectral files used to set
Vela timing and compare the approximate gamma-ray calculation with data.
Provenance, source URLs and hashes accompany the files. The original
spectral FITS has invalid embedded checksum cards; its recorded external
hash and repeated-download audit are preserved.

These data do not define a 3D radiation pattern. The present model remains
discrepant from the observed pulse shape and spectrum.
